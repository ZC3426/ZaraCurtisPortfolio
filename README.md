# Zara Portfolio 1

UX design &amp; research portfolio for Zara Curtis — psychology-backed UX Designer &amp; Researcher based in the UK &amp; Ireland.

Plain HTML/CSS, no build step, no dependencies — safe to host anywhere as static files.

## Pages

- `index.html` — Home
- `about.html` — About Me
- `case-studies.html` — All case studies
- `projects/sketchscroll.html`
- `projects/equil.html`
- `projects/neurodivergence-in-schools.html`
- `projects/risky-driving.html`

## Hosting on GitHub Pages

1. Push this repo to GitHub (already done if you're reading this from the repo).
2. Go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Pick the `main` branch and `/ (root)` folder, then **Save**.
5. GitHub will publish the site at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Editing

- Update contact details, links, and copy directly in the HTML files.
- Shared styling lives in `styles.css` — colors are defined as CSS variables at the top for easy theme changes.
- Add a new case study by duplicating a file in `projects/`, then linking to it from `index.html` and `case-studies.html`.
